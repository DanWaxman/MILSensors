Sensor Design Module
====================

The ``sensor_design`` module provides high-level utilities for MIL-based sensor network design with spatiotemporal Gaussian Processes. It includes helpers to build default kernels, train an ST-VGP model on simulator-derived data, and extract inducing points and variational quantities for analysis.
